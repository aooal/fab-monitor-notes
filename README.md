# Fab Monitor 開發筆記

Fab Monitor 專案(模擬晶圓廠批次與設備事件的微服務練習專案)的開發筆記網站。純靜態 HTML/CSS/JS,沒有建置步驟。

> 這是個人練習專案,所有資料皆為模擬,與任何真實半導體廠或其內部系統無關。

## 在本機看

直接用瀏覽器開啟 `index.html` 即可。

## 部署到 GitHub Pages

1. 把這個資料夾推上一個**公開**的 GitHub repo(`main` 分支)。
2. 到 repo 的 Settings → Pages。
3. Source 選 `Deploy from a branch`,Branch 選 `main`,資料夾選 `/ (root)`,按 Save。
4. 等一兩分鐘,網址會是 `https://<你的帳號>.github.io/<repo 名稱>/`。

所有連結都是相對路徑,放在子路徑下也能正常運作。
